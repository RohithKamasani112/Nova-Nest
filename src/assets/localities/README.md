# Locality discovery photographs

These photographs are local frontend assets used only for missing/broken locality covers. They are not added to property records, cards, details, PDFs or S3 data. Existing working listing images take precedence. CSS crops the images to the square card.

- whitefield.jpg: **Whitefield view**, Doc.aneesh, 10 April 2012. [Source](https://commons.wikimedia.org/wiki/File:Whitefield_view.jpg). [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). 960px Wikimedia thumbnail.
- hoodi.jpg: **Hoodi Metro**, Chaitanya / ChaitanyaJo, 22 June 2023. [Source](https://commons.wikimedia.org/wiki/File:Hoodi_Metro.jpg). [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). 960px Wikimedia thumbnail.
- mahadevapura.jpg: **Phoenix Mall Bangalore Night View**, Veera.sj. [Source](https://commons.wikimedia.org/wiki/File:Phoenix_Mall_Bangalore_Night_View.JPG). [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The Whitefield city view is the generic Bengaluru fallback for other localities without usable listing photos; its alternative text describes the actual city view rather than claiming it depicts another locality. Source, author and licence links are available in the Locality photo credits disclosure beneath the carousel. Photo assets retain their original licences.
